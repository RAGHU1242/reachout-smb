# Multi-Tenant Billing & Monetization Roadmap

ReachOut SMB is structured for SaaS monetization across three subscription tiers:

## Proposed Pricing Tiers

| Feature | Starter (₹1,499 / mo) | Growth (₹3,999 / mo) | Pro (₹8,999 / mo) |
| :--- | :--- | :--- | :--- |
| **Connected Channels** | 1 (Instagram OR WhatsApp) | 2 (Instagram AND WhatsApp) | Unlimited Channels |
| **AI Conversations** | 500 / month | 2,500 / month | 10,000 / month |
| **Product Catalogue** | Up to 50 items | Up to 500 items | Unlimited |
| **Multilingual Support** | Telugu & English | Telugu, Hindi, English | All Indian Languages |
| **Human Handoff** | Basic | Real-time desktop alerts | Priority WhatsApp notifications |
| **Custom Knowledge Base**| Standard FAQs | Vector-search document chunks | Dedicated brand voice training |
| **Transaction Fee** | 1.5% per order | 0.8% per order | 0% transaction fee |

## Tracked Metering Counters

The backend schema is already prepared to track:
- AI conversation turns
- Order volume & revenue
- Connected channel accounts
- Media asset storage usage
